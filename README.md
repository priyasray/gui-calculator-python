# GUI Calculator - Python

A simple, clean calculator with graphical user interface built using **Tkinter**.

### Features
- Basic arithmetic operations (+, −, ×, ÷)
- Clear (C) functionality
- Nice button layout and readable design

### Requirements
- Python 3.x

### How to Run
```bash
git clone https://github.com/priyasray/gui-calculator-python.git
cd gui-calculator-python
python calculator.py
# or
python3 calculator.py
